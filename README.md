# THE FIRST COFFEE — QR-Based Cafe Management System

### Business Information
- **Cafe Name**: THE FIRST COFFEE
- **Location**: Karve Road, Opp. Ranka Jewellers, Erandwane, Pune, Maharashtra, India
- **Hours**: 9:00 AM to 5:00 AM
- **Phone / Inquiries**: Available at counter

### Project Description
QR-based cafe ordering and management system engineered for college IT engineering project.
Allows customers to scan a table-specific QR code, browse authentic menu categories with live search, add items to cart, and place orders directly to the counter.
Staff manage incoming orders, track preparation status (Received -> Accepted -> Preparing -> Ready -> Completed), and verify payments through a secure admin dashboard.

### Preserved Assets & Database
- 12 verified categories
- 54 menu items with actual prices in INR
- 5 registered tables (Table 01 to Table 05)
- Cloud Supabase PostgreSQL database
- Preserved brand typography (`Fraunces` + `Inter`) and espresso/caramel/cream palette.
